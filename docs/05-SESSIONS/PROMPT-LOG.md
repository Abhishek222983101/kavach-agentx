# Raw prompt log

> **What this is:** Every prompt the owner types, captured automatically by `.claude/hooks/log-prompt.mjs`.
> **Do not edit this file.** It is append-only and machine-written. The agent summarises it in `SESSION-LOG.md` and analyses it in `PROMPTING-PATTERNS.md`.
> **Privacy:** common secret patterns are redacted, but this is not a guarantee. Do not paste passwords, API keys, or customer personal data into chat.

## Format

Each entry is a dated heading followed by the prompt in a fenced block. New entries are appended at the bottom, in chronological order.
