# Archive

Superseded content goes here. The notebook never silently deletes history.

## Rules

- Move the old text here instead of deleting it.
- Name the file with the original path and the date: `PRD-2026-11-10-superseded-scope.md`.
- Add a one-line note at the top: what it was, why it was replaced, and what replaced it.
- Link to the replacement.
- If a decision was reversed, record it in `docs/04-DELIVERY/DECISIONS.md` under **Reversed or superseded decisions**.
